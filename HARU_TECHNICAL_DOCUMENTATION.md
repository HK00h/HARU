# HARU — Technical Documentation

## 1. Project Overview

HARU is a Web3 project deployed on BNB Smart Chain Mainnet. The project aims to build an accessible Web3 ecosystem combining a BEP-20 compatible token with wallet connectivity, blockchain interaction, and a Web3 dashboard.

## 2. Problem

New Web3 users can find wallet connections, token balances, blockchain transactions, and decentralized applications difficult to understand and use.

HARU aims to simplify these interactions through a straightforward Web3 interface and practical blockchain functionality.

## 3. Proposed Solution

HARU plans to develop:

- Web3 wallet connectivity
- HARU token dashboard
- On-chain balance and transaction information
- Blockchain transaction functionality
- User-friendly Web3 interfaces
- Future integrations with the BNB Chain ecosystem

## 4. Token Information

- Token Name: HAR
- Token Symbol: HARU
- Network: BNB Smart Chain
- Token Standard: BEP-20 compatible
- Total Supply: 100,000,000 HARU
- Decimals: 18
- Status: Deployed on BNB Smart Chain Mainnet

## 5. Smart Contract

**Contract Address:** `0x43054bb04e5bBd5153486396989e3C45424392C0`

**Deployment Network:** BNB Smart Chain Mainnet

The HARU smart contract has been developed and compiled using Solidity and OpenZeppelin's ERC-20 implementation.

The contract is designed to create the initial HARU token supply and assign that supply to the deploying address.

## 6. Current Development Status

HARU is currently in the development and pre-launch stage.

The smart contract has been developed and compiled. BNB Smart Chain Mainnet deployment and subsequent Web3 product development are planned milestones.
