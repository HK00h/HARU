# HARU

HARU is a Web3 project deployed on BNB Smart Chain Mainnet.

## Token

- Name: HAR
- Symbol: HARU
- Network: BNB Smart Chain
- Standard: BEP-20 compatible
- Total Supply: 100,000,000 HARU
- Decimals: 18
- Status: Deployed on BNB Smart Chain Mainnet

## Project

HARU aims to develop an accessible Web3 ecosystem with:

- Web3 wallet connectivity
- HARU token dashboard
- On-chain balance information
- Transaction information
- Blockchain interaction
- Future BNB Chain integrations

## Current Status

The HARU smart contract has been developed and compiled.

BNB Smart Chain Mainnet deployment is complete.

## Transparency

HARU is currently a pre-launch project.

HARU is not USDT and is not represented as USDT.

The project does not guarantee investment returns or token value.
